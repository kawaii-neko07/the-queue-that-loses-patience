# The Queue That Loses Patience

An interactive queue simulation created in **Godot 4.7.2**. A single rule — whether waiting agents can run out of patience — changes the behavior of the entire system.

## Play

**[Launch the web simulation](https://YOUR-USERNAME.github.io/the-queue-that-loses-patience/)** — replace `YOUR-USERNAME` with your GitHub username after enabling GitHub Pages.

The web build in [`docs/`](docs/) is the **original Godot Web export**, not a JavaScript rewrite. The source project is in [`godot-project/`](godot-project/).

## How it works

Agents arrive at random intervals, join a first-in-first-out (FIFO) queue, and are served one at a time. When patience is enabled, waiting agents leave after their individual waiting limit. The interface shows agent states, completed services, abandonments, and queue length.

**Controls:** Toggle patience ON/OFF, pause/resume, and restart.

## What was tested

- With patience disabled, the queue grew to 66 waiting agents with zero abandonments (at approximately 96 seconds).
- After enabling patience during the run, the queue fell to 24 waiting agents and abandonments rose to 56 (at approximately 116 seconds).
- Pause and restart were manually confirmed to work.

These are observations from one interactive run, **not** a controlled experiment with matched random seeds. The arrival rate is intentionally higher than the single station's service capacity.

## Run the source in Godot

1. Install a compatible Godot 4 version (created with **Godot 4.7.2**).
2. In Godot Project Manager, import `godot-project/project.godot`.
3. Press **F5** to run the main scene.

## Run the web build locally

Do not double-click `index.html` using `file://`: browsers typically block required asset requests. Instead, from the `docs` directory run:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000/>.

## Publish on GitHub Pages

1. Push this repository to GitHub using **GitHub Desktop or Git** (the `.wasm` file exceeds GitHub's 25 MiB browser-upload limit).
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main`, folder `/docs`, and **Save**.
5. Once deployment completes, use `https://YOUR-USERNAME.github.io/the-queue-that-loses-patience/` (substitute your username).
